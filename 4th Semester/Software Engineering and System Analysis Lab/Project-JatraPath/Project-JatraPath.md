# JatraPath

JatraPath is a Bangladesh-focused travel platform designed to help people discover beautiful destinations, hidden gems, local experiences, and travel guides across the country.

## Features

- Explore popular tourist destinations
- Discover local foods and culture
- Travel blogs and guides
- Trip planning assistance
- User-friendly and responsive design

## Mission

Our mission is to make traveling across Bangladesh easier, smarter, and more enjoyable for everyone.

## Tech Stack

- React.js
- PHP
- MySQL
- CSS
